## 四、核心学术发现与机制澄清

1. **为什么全程平均 Scan 开销与稀释版 LS24 存在表面差异？**
   - **轨迹与阶段分布差异**：稀释版 LS24 将 20,000 个删除分散在 Phase A (10k)、Phase B (5k)、Phase C (5k) 中，导致全程三个阶段均处于墓碑污染状态（Scan 开销分别为 $14.8\text{ μs/key}$、$40.8\text{ μs/key}$、$31.1\text{ μs/key}$，全程加权平均为 $25.98\text{ μs/key}$）；
   - **密度保持版聚焦突发**：DensityPreserved 将 20,000 个大跨度墓碑全部集中在 Phase B 突发期，使 Phase A 呈现纯净基线（$0.78\text{ μs/key}$），Phase C 呈现读恢复（$2.01\text{ μs/key}$）；
   - **突发期真实退化更严峻**：在集中注入墓碑的 Phase B 期间，DensityPreserved 的 Scan 开销达到 **$45.68\text{ μs/key}$**，**高于稀释版 LS24 的 $40.79\text{ μs/key}$**；相对同轨迹 Clean 基线（$0.78\text{ μs/key}$）发生 **58.56 倍绝对退化**，点查 P99 发生 **461 倍退化**。
2. **固定阈值两难困境在大规模高密度下得到严密证实**：
   - $T=256$ 虽将读延迟压低，但触发 74.7 次下刷并引起 **16.04 GB Compaction 写入**（PWA 达 939.5x），导致 Phase B 的 **Put P99 飙升至 8.33 ms**；
   - $T=2048$ 保护了写端（Put P99 仅 0.16ms），但点查删除尾延迟增加至 $357.7\text{ μs}$（为 T=256 的 2.15 倍），且失效键丢弃滞后（少丢弃 7.34M 键）。
